
Das Framework dbselftables siehe development branch auf https://github.com/kollia/dbselftables/tree/development
erzeugt für das Objekt STProjectUserSiteCreator einen Titel. (Bitte auch README vom Projekt berücksichtigen)
In meinem Beispiel File im workspace unter /html/index_mug.php den Titel "Kinderradiologie"
dieses File greift auf das Framework von dbselftables zu welches im workspace auf /php_includes/selftables0.0.5.12-SNAPSHOT_linux_local/ liegt. Der Titel wird korrekt im Browser angezeit und wird über getTitle() aus dem STBaseContainer objekt erzeugt.
STProjectUserSiteCreator bietet ein Projekt-Management in dem ich verschiedene Projekte eintragen kann auf die es dann Verlinkt.
Da dieses Management das andere Projekt in einem  Frameset anzeigt, welcher zuerst den Container STProjectUserFrame mit dem default Titel ProjectFrame verwendet, wird der Titel "Kinderradiologie" mit dem Titel "ProjectFrame" verwendet. Obwohl eigentlich der Projektname zb. "Stationsplan" aus der Datenbank verfügbar wäre.

Frage: kannst Du mir das Framework so ändern dass er dann den Projekt Namen aus der Datenbank nimmt und "Kinderradiologie - Stationsplan" schreibt und nicht "Kinderradiologie - ProjectFrame"!?


Die externen Projekte können unabhängig vom Framework sein, oder so wie in meinem fall der Stationsplan aus dem Repository
https://github.com/kollia/hospital_stationplan liegt im workspace unter /html/stationplan_linux/ welches ebenfalls auf das Framework zugreift.
Dieses Projekt erzeugt ebenfalls korrekt den Titel Stationsplan
